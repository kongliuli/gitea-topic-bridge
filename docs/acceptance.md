# 实施顺序与上线门槛

以下 1–4 是完整上线门槛，尚未全部通过。已通过的局部测试单独记录在末尾。

1. **底座**：干净 Windows 测试机，校验官方二进制，配置专用账户、回环监听、SQLite 和网关。重启后验证服务自动恢复。通过指定出站路径建立一个公开测试镜像，普通开发者推送镜像必须失败。
2. **后端**：三个合成仓建同名 Topic，逐项比对 API 的 PR、head SHA、CI 与冲突。直接推送受保护主干须失败；无权用户不能借 Bridge 合并或查看回执。重复、乱序与伪造 webhook 分别验证去重、回查与拒绝。
3. **网页**：从 Gitea 菜单打开总览、联调、回执中心；验证 OAuth 返回原页。分别从内网、域名、IP:端口、tailnet 客户端检查证书、登录回调、克隆 URL 和网页链接。非授权网络不能直连后端。模拟三仓两成功一冲突，网页不得显示全部成功；检查回滚 PR 仍需审批。
4. **交付与迁移**：对同一制品独立计算 SHA-256，检查 JSON、Markdown 与签名一致；篡改副本须验签失败。在空目录恢复备份并重复核验。先接一个非关键项目，通过后才分批导入；保留旧仓和切换记录，不搬动历史目录。

## 已验证：本地只读查询

使用 Windows amd64 的 Gitea v28.4.0，测试前将二进制的 SHA-256 与该版本 GitHub 发布资产的摘要核对。配置 Git 后，可在 PowerShell 中复现：

```powershell
$env:BRIDGE_TEST_GITEA_BINARY = 'C:\path\to\gitea-28.4.0-windows-amd64.exe'
go test -v -timeout 3m -run '^TestGiteaLocalLab$' -count=1 ./...
```

测试创建临时回环实例和 SQLite 数据库，自动生成测试账号及令牌，运行后停止实例。一个账号建立四个私有测试仓，Bridge 查询使用另一个普通账号的授权。验证已合并和开放 PR、同仓多个匹配、分页上限、相近编号不误匹配、不可见仓过滤，以及撤销仓库权限后不再返回该仓。

同一测试还提交真实 Gitea 登录和 OAuth 授权表单，经回调进入 Bridge，在会话中查询私有仓，再退出并确认 API 返回 `401`。测试为开放 PR 提交合成的 CI 成功/失败状态和一条正式批准，核对返回的 CI、批准数量、变更文件数；有冲突的样例与无冲突的样例呈现不同状态，但 `mergeable=false` 不会被当作已确认冲突。这是本地 HTTP 流程测试，不代表已验证浏览器渲染、生产 TLS、Gitea 菜单、CI 运行器或分支保护策略。

## 已验证：保存联调单

`go test ./...` 验证 Bridge 使用 SQLite WAL，关闭并重开数据库仍能读取原联调单，失败事务不会留下半张单，且不会改写非 Bridge 数据库。上述 Gitea 联调还验证普通账号建单、重复提交返回同一张单、同键不同内容报冲突、拒绝跨站写入，以及仓库权限撤销后无法读取原单或用原键重试。当前未验收主机重启或备份恢复。

## 已验证：同仓分支批量建 PR

本地 Gitea 联调用普通写权限账号验证同批次中新建 PR、复用已有 PR、以及源分支不存在导致的失败分别记录；再次提交保留已完成结果，只读账号不能写入。模拟 HTTP 测试验证请求超时后重开同一数据库，回查为空不重发请求，原 PR 稍后出现（即使已合并）可通过操作标识恢复关联。此测试未覆盖跨 Fork 提交、合并或网页渲染。

## 已验证：逐仓合并

相同的本地 Gitea 测试使用普通协作者的 OAuth 会话，对三个私有仓逐个确认：两个通过审批后成功，一个有冲突仍受阻。实际验证了错误提交 SHA、未批准、降为只读、跨站请求、缺少必跑检查均不能合并；也验证向受保护分支直接写文件的 API 操作被拒绝。两个成功结果的合并 SHA 和执行人与 Gitea 一致。模拟测试另验证未受保护的目标不会收到合并请求，以及请求超时后换联调单、重开数据库都不会重复提交，稍后可核对已完成的结果。未验证真实 Git 推送拒绝、浏览器渲染、反向 PR 或生产网络。

## 已验证：反向 PR

本地 Gitea 测试验证目标分支前进后拒绝自动准备，也不会新建分支；符合条件时用当前协作者建反向 PR，创建与重试不改主干、不重复开单。给反向 PR 补齐 CI 后，仍须另行人工批准才能合并；审批后由 Gitea 合并，验证原 PR 新增文件已撤回。模拟测试覆盖两阶段超时、数据库重开后回查、只读核对与恢复原 PR 关联。尚未验收浏览器渲染或生产网络。

## 已验证：内部 Webhook

本地 Gitea v28.4.0 实际向独立回环入口投递 PR 与 Release 事件；只读协作者令牌回查得到合并 SHA、带注解的斜杠标签所指提交、执行人及时间。模拟测试覆盖无效签名、非回环请求、仓库白名单、重复 UUID、同 UUID 内容不一致、早到/迟到事件及租约中断后数据库重开重试。没有启用生产网关入口，尚未验收制品快照、签名与回执导出。
